# Storytelling Guide

## Default Technical Talk Flow

1. Hook: one visual that explains why the topic matters.
2. Agenda: a short map matching the real slide order.
3. Risk/problem: what can go wrong if the audience does not change behavior.
4. Demo: concrete project or artifact.
5. Method: repeatable workflow or decision process.
6. Guardrails: tools, skills, checks, approval points.
7. Review: how to inspect and accept work.
8. Practical habits: shortcuts, prompt workflow, reusable scripts.
9. Close: reinforce ownership and verification.

## 15-Minute Talks

Keep the deck to roughly 8-12 slides. Use fewer words because the speaker carries nuance. Put implementation details in speaker notes or backup files, not the main slide.

## Reordering Rule

If a slide visually explains the whole talk, move it near the beginning. Then update the agenda immediately.
