# Validation Report Template

Use this structure in the final response when validation matters.

```text
Validation:
- Selected level: <level and name>
- Ran: <commands/tools or none>
- Result: <passed/failed/skipped>
- Skipped: <checks skipped and why>
- Residual risk: <short note>
```

Keep the report short. Do not list every log line unless the user asks for it.
